# Truck Manager Backend / Simulation

This folder is for the Truck Manager simulation and backend systems.

Planned responsibilities include:

- Game clock
- Driver hours and fatigue
- Automatic co-driver switching
- Load generation
- Automatic and manual dispatch logic
- Route progression
- Fuel and maintenance simulation
- Company finances
- Staff effects
- Facility systems
- Save/load state

The simulation layer should remain independent from the UI so the same logic can serve mobile and desktop clients.
